# Grapharch

Documentation starts with a graph.

Grapharch collects authored text, ontology constructs, and documentation hints
into a shared knowledge graph. Publication targets select and arrange those
fragments into websites, specifications, and PDF documents.

This documentation website is generated by Grapharch from its own documentation
graph. The topics, examples, navigation, and downloadable vocabularies all pass
through the same collection, assembly, planning, and rendering pipeline.

## One graph, several publications

A Markdown file supplies prose. An RDF file supplies documentable constructs.
Frontmatter and RDF annotations describe what belongs together. The resulting
KG identifies topics, fragments, examples, provenance, and publication structure.

Renderers consume a pinned graph revision. They can arrange the same content
for a documentation website, a formal specification, or a review document.
Changing the presentation does not require copying the source material.

## Implementation and direction

The Rust implementation includes embedded Oxigraph storage, specialized
collectors, bounded parallel ingestion, immutable revisions, target planning,
static HTML, and embedded Typst/PDF generation. It remains under development.

Read the [implementation status](other/status.md) for the distinction between
working capabilities and the broader [design goals](design-goals/README.md).
The [delivery contract](other/architecture/deliverables.md) records the remaining
acceptance criteria.
