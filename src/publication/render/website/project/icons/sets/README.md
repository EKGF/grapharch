# Bundled Material for MkDocs icon sets

`icons.bin` holds the icon sets that Material for MkDocs exposes as
`:material-*:`, `:octicons-*:`, `:simple-*:` and `:fontawesome-*:` shortcodes.
It is generated by `generate.py` from these pinned npm tarballs:

Font Awesome stays on the 6.x line that Material for MkDocs 9 ships, so the
shortcode names match. Only the SVG icons are bundled: no fonts, CSS or
JavaScript. The generator keeps each icon's `viewBox` and `<path>` geometry
unchanged and drops titles, comments, IDs and fixed fills, so publications
colour icons with `currentColor`. Simple Icons are brand logos; their
trademarks remain with their owners (see the disclaimer). Every publication
that uses the bundle ships these notices in `grapharch-icon-licenses.txt`.

To regenerate, download and extract the four tarballs, check their integrity,
then run:

```sh
python3 -I generate.py MDI/package OCTICONS/package SIMPLE/package FA/package icons.bin
```
