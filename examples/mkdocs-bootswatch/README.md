# Independent MkDocs documentation

This showcase imports [MkDocs Bootswatch Themes](https://github.com/mkdocs/mkdocs-bootswatch) at commit `374197dbc3b89b830075b7d67c66c9407968855a`. The source authors are Tom Christie and Dougal Matthews; the original BSD 2-Clause `LICENSE` is retained as a downloadable publication asset.

Only the explicitly selected documentation, configuration and license are read from immutable Git blobs. GraphArch interprets the configuration and Markdown directly: it does not install or execute MkDocs, Python plugins, or the Bootstrap theme runtime. The published screenshots are original source images. HTML and the retained graph are the available outputs; no PDF is advertised.

The imported source bytes and Git provenance are retained in the exported graph, so rendering does not require the original checkout or Git cache.
