# Rust crate documentation without configuration

This showcase publishes [dotenvage](https://github.com/legra-ai/dotenvage) at commit `f8810672ced3648cfc32db00898abb84a6515eb0`. dotenvage is a Rust crate and command-line tool with Node.js and Python bindings, maintained by DataRoad Inc and dual-licensed under MIT or Apache-2.0. Both license texts are retained as downloadable publication assets.

The repository contains no GraphArch configuration. The showcase selects its README, contributing guide and binding guides, and GraphArch applies the same zero-configuration defaults as `grapharch build`. No repository file is executed.

The README is the home page, the Markdown headings become the page contents, and search, provenance and the retained documentation graph are generated. Rust API reference from rustdoc is not yet extracted; the crate's API documentation remains on docs.rs.
