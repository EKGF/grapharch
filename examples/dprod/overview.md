DPROD extends DCAT to describe data products and data services in a decentralized
way. Its definition of a data product emphasizes a rational, managed, and governed
collection of data with purpose, value, and ownership.

## Documentation from the graph

The ontology and SHACL files are collected independently. A specialized annotated-term
documentor reads explicit English labels and Dublin Core descriptions from the
pinned RDF graph and generates one reference fragment for each term. It preserves
comments as notes and outgoing assertions as a predicate/value table. Relationships
between documented terms become internal links with checked publication references.

## Reading the reference

The sections below cover OWL classes and properties, a SKOS concept scheme, and
SHACL node/property shapes. Each term includes its identity, authored definition,
and RDF facts. The final section is the native dataset-schema worked example.

This is a reference-generation example. It does not claim full ReSpec compatibility,
complete import closure, inference, or execution of the SHACL validation rules.
