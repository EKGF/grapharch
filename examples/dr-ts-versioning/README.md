# TypeScript package documentation without configuration

This showcase publishes [@dataroadinc/versioning](https://github.com/legra-ai/dr-ts-versioning) at commit `2249068ccef37e996e00a394e18c0ae9ac67b952`. It is a TypeScript command-line package by DataRoad Inc under the MIT license, which is retained as a downloadable publication asset.

The repository contains no GraphArch configuration. The showcase selects its README, changelog and guides, and GraphArch applies the same zero-configuration defaults as `grapharch build`. No package script is executed. The upstream guide index links to `package.json`; GraphArch rejects links to files that are not published, so that index is not selected.

The handwritten API reference is published as authored. TypeScript declarations are not yet extracted into a generated API reference.
